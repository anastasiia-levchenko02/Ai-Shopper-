# AI Personal Shopper — на офіційному МСР «Сільпо»

Агент, який із запиту гостя (**бюджет + кухня + дієтичні обмеження + привід**)
складає **меню з рецептами** та **готовий до оформлення кошик** через офіційний
MCP «Сільпо» (`https://mcp.silpo.ua/mcp`). Плюс регулярний режим **«Здивуй мене»** —
щотижневий/щомісячний кошик на основі історії покупок.

## Гість і проблема

Зайнята людина замовляє продукти в «Сільпо» і щоразу окремо: вигадує меню,
перераховує порції, звіряє алергії/бюджет, збирає кошик. На нестандартний привід
(побачення, гості) ідей немає взагалі. Наслідок для бізнесу — кинуті кошики,
менший чек, рідші замовлення.

## Що робить агент (агентний сценарій, а не FAQ-бот)

Запит: _«Вечеря на 5, без свинини, у гостя алергія на моркву, бюджет 2000 грн, щось італійське»_

**Крок 1 — меню (`POST /api/menu`, без походу в кошик):**

1. **Розбирає запит** — порції, бюджет, кухня, привід, виключення (детерміновано; з LLM — точніше).
2. **Персоналізація з МСР** — `silpo_get_my_profile`, `silpo_get_my_family`,
   `silpo_get_my_food_restrictions` (додає «без свинини» з профілю).
3. **Меню** — бюджет/особу класифікується в сегмент (`економний` / `середній` /
   `преміум` / `лакшері`), і шаблон меню підбирається саме під нього: якщо
   м'ясна/сирна страва не по кишені, агент сам обирає овочеву чи рибну (на тунці)
   того самого стилю кухні, а не намагається втиснути делікатеси в дешевий бюджет.
   Бібліотека — 14 страв: сніданок, вечеря, обід, гості, романтичне побачення ×
   італійська, азійська, українська, грузинська, середземноморська, мексиканська
   кухня, у всіх 4 сегментах. Далі — масштабування на потрібну кількість порцій,
   агрегація однакових інгредієнтів між стравами, перевірка кожного інгредієнта
   на виключення гостя.

Тут гість бачить рецепт і може **відмітити чекбоксом «є вдома»** — сіль вже є, олія
є, ще щось лишилось із минулого замовлення. Ці інгредієнти лишаються в рецепті, але
не йдуть у кошик.

**Крок 2 — кошик (`POST /api/cart`, з урахуванням «є вдома»):**

4. **Контекст кошика** — `silpo_get_my_shopping_cart` → (`silpo_find_address` →
   `silpo_get_available_delivery_types` → `silpo_create_shopping_cart` за потреби) →
   `silpo_get_shopping_cart_by_id` → `silpo_get_time_slots` (валідація слота).
5. **Улюблені** — `silpo_get_my_favorites` (їх агент не замінює).
6. **Інгредієнти → товари** — `silpo_find_products_batch`, `silpo_get_promotions`;
   позначені «є вдома» — пропускаються. Серед знайдених товарів обирається
   найдешевший релевантний варіант (не перший-ліпший).
7. **Оптимізація під бюджет** — `silpo_get_similar_products` для замінних позицій
   (улюблені бренди не чіпає), прибирання необов'язкових інгредієнтів.
8. **Складання** — `silpo_add_or_update_cart_products` → `silpo_get_shopping_cart_by_id`
   (підсумок, `validations[]`); пропозиція застосувати балабонуси.

Кожен виклик JSON-RPC видно у вкладці **«Трейс МСР»** (вимога хакатону).
`POST /api/plan` лишається як односхідцевий флоу (без «є вдома») — його ж
використовує «Здивуй мене».

### Свайп кількох варіантів

Кнопка «🔀 Кілька варіантів» (`POST /api/menu-options`) замість одного
найкращого меню повертає топ-5 релевантних шаблонів під ті самі обмеження —
гість гортає картки (свайп вправо = обираю, вліво = далі) замість нав'язаного
єдиного рішення. Обрана картка веде в той самий крок 2 (`POST /api/cart`),
що й звичайний флоу.

### «Здивуй мене»

`silpo_get_my_online_orders` + `silpo_get_my_offline_orders` → антиповтор нещодавніх
страв і вибір «свіжої» кухні → той самий флоу складання кошика → `silpo_get_product_sets`
як джерело ідей. Запуск: `npm run surprise -- 900`.

## Запуск

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env
npm run dev
# http://localhost:5173
```

За замовчуванням `SILPO_MODE=mock` — вбудовані відповіді у форматі 40 tools МСР,
працює без акаунта «Сільпо». Демо-сценарій: кнопка «Італійська вечеря на 5».

Перевірити логіку без UI й без жодного мережевого виклику (безпечно, ніколи не
чіпає live-акаунт незалежно від `.env`):

```bash
npm run smoke
```

### Реальне підключення до МСР «Сільпо»

```env
SILPO_MODE=live
```

При першому запиті відкриється браузер для входу в акаунт «Сільпо»
(OAuth 2.1 + PKCE). Після логіну повернення на `/oauth/callback`, MCP-токен
зберігається серверно у `tokens/` (у клієнтський код не потрапляє).

### LLM-режим (опційно)

```env
SILPO_LLM=on
ANTHROPIC_API_KEY=sk-ant-...
```

Вмикає генерацію меню та замін через Claude API. Без ключа працює
детермінований template-режим із вбудованої бібліотеки меню.

## Цінність

- **Гість:** меню + список + замовлення за один запит; контроль бюджету;
  враховані алергії; різноманіття; менша втома від рутини.
- **«Сільпо»:** ↑ середній чек і частота замовлень, ↓ кинуті кошики,
  крос-продаж акційних позицій, підписка «Здивуй мене» = утримання,
  дані про смаки для персоналізації.

## Валідація гіпотези

A/B «агент проти звичайної доставки»: середній чек, конверсія кошик→замовлення,
retention підписки на 30 днів; % рекомендованих позицій, доданих у кошик;
5–10 інтерв'ю після реального замовлення; юніт-економіка (приріст маржі vs
вартість токенів генерації).

## Інтеграція

- Розділ «AI Кухар» у застосунку/на сайті «Сільпо» в блоці доставки.
- Бот у Viber/Telegram поверх того самого backend.
- Окремий продукт-підписка «Здивуй мене».

## Стек

Node + TypeScript + Express, `@modelcontextprotocol/sdk` (Streamable HTTP + OAuth),
`@anthropic-ai/sdk` (LLM-режим), ванільний фронтенд без збірки.

## Структура

```
src/
  config.ts            env / прапорці режимів
  trace.ts             збір і стрім кроків агента (NDJSON → UI)
  mcp/
    client.ts          спільний контракт SilpoClient + фабрика
    live.ts            реальний MCP-клієнт + OAuth 2.1/PKCE провайдер
    mock.ts            підмножина 40 tools на демо-даних
    catalog.ts         демо-каталог товарів
  agent/
    constraints.ts     детермінований парсер запиту гостя
    menus.ts           бібліотека шаблонів меню + вибір під обмеження
    planner.ts         масштабування, агрегація інгредієнтів
    orchestrator.ts    агентний ланцюжок викликів МСР
  jobs/surprise.ts     регулярний кошик «Здивуй мене»
  server.ts            HTTP + стрім трейсу + OAuth callback
public/                односторінковий UI (меню · кошик · трейс МСР)
```
